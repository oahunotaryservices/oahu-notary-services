When a new public page is added:
1. Add it to the main navigation if appropriate.
2. Add it to sitemap.xml.
3. Add a self-referencing canonical URL.
4. Confirm the page title and meta description.
5. Test the page on both desktop and mobile.


CONTENT / PRIVACY NOTES
-----------------------

Do not place client documents, IDs, private legal documents, passwords, account information, or other sensitive information in the public website files.

Use the secure document-upload link on the website for client document submissions.

The website provides notary-related information and services. It should not be written in a way that suggests legal advice is being provided.
